MIT LAB STARTUP

1. Open Terminal.

2. Enter the MIT project folder:

cd "$HOME/Documents/MIT-RAG-Context-Engineering"

3. Activate the virtual environment:

source .venv/bin/activate

4. Confirm Python:

python --version

code .

deactivate
